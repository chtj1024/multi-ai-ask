# Multi AI Ask

질문 하나를 **Claude, ChatGPT, Gemini에 동시에** 보내는 크롬 확장 프로그램입니다.

AI마다 탭을 열고 같은 질문을 복사해서 붙여넣을 필요 없이, 입력창 하나에 질문을 쓰면 선택한 AI 사이트에 한 번에 전송됩니다.
크롬에 로그인된 계정을 그대로 사용하므로 **API 키나 추가 비용이 필요 없습니다.** (Pro, Plus 같은 구독도 그대로 적용)

## 주요 기능

- **동시 전송** — 질문 하나를 선택한 AI 사이트에 동시에 보냅니다
- **로그인 상태 표시** — 팝업에서 각 사이트의 로그인 여부를 점으로 보여주고 (🟢 로그인됨 / 🔴 로그인 필요), 로그인 안 된 사이트에는 보내지 않습니다
- **새 대화 / 이어서 질문** — 매번 새 채팅을 열거나, 이미 열려 있는 대화에 이어서 질문할 수 있습니다
- **창 나란히 배치** — 세 AI를 각각 창으로 띄워 화면을 등분하므로 답변을 한눈에 비교할 수 있습니다
- **전송 결과 표시** — 아이콘 배지에 성공 개수(`3/3`)가 뜨고, 실패한 사이트는 팝업에 이유가 나옵니다
- **단축키** — `Alt+Shift+A`로 팝업 열기, `Ctrl+Enter`로 전송
- 작성 중이던 질문과 설정은 팝업을 닫아도 유지됩니다

## 설치

크롬 웹 스토어에 올라가 있지 않으므로 직접 불러와서 설치합니다.

1. 이 저장소를 내려받습니다
   ```bash
   git clone https://github.com/chtj1024/multi-ai-ask.git
   ```
   또는 GitHub에서 **Code → Download ZIP**으로 받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 내려받은 `multi-ai-ask` 폴더 선택
5. 주소창 옆 퍼즐 아이콘에서 **Multi AI Ask**를 고정(📌)하면 편합니다

처음 한 번은 [claude.ai](https://claude.ai), [chatgpt.com](https://chatgpt.com), [gemini.google.com](https://gemini.google.com)에 각각 로그인해 두세요.

## 사용법

1. 확장 아이콘을 누르거나 `Alt+Shift+A`
2. 보낼 AI를 선택 (Claude / ChatGPT / Gemini)
3. 질문을 입력하고 **동시에 보내기** 또는 `Ctrl+Enter`

| 옵션 | 설명 |
|---|---|
| 새 대화로 시작 | 켜면 매번 새 채팅을 열고, 끄면 열려 있는 대화에 이어서 질문합니다 |
| 창 나란히 배치 | 켜면 AI마다 창을 따로 띄워 주 모니터를 가로로 등분합니다 |

## 동작 방식

1. 팝업에서 질문을 보내면 백그라운드 스크립트가 각 AI 사이트의 탭을 찾거나 새로 엽니다
2. 페이지가 로드되면 입력창을 찾아 질문을 넣고 전송 버튼을 누릅니다
3. 입력창이 비워지면 전송된 것으로 판단하고 결과를 팝업과 배지에 표시합니다

로그인 여부는 각 사이트의 로그인 쿠키가 있는지로 확인합니다. 쿠키 값은 읽기만 하고 어디에도 보내지 않습니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 프로그램 설정과 권한 |
| `sites.js` | 사이트별 주소, 로그인 쿠키, 입력창·전송 버튼 선택자 |
| `background.js` | 탭 열기, 로그인 확인, 질문 입력과 전송 |
| `popup.html` / `popup.css` / `popup.js` | 팝업 화면 |

## 권한

| 권한 | 용도 |
|---|---|
| `tabs`, `scripting` | AI 사이트 탭을 열고 질문을 입력 |
| `storage` | 설정과 작성 중인 질문 저장 |
| `system.display` | 창 나란히 배치할 때 화면 크기 확인 |
| `cookies` | 로그인 여부 확인 |
| `claude.ai`, `chatgpt.com`, `gemini.google.com` | 각 사이트에 질문 입력 |
| `google.com` | Gemini의 구글 로그인 쿠키 확인 (`.google.com`에 저장되어 있음) |

## 알려진 문제

- **ChatGPT, Gemini 전송 실패** — 현재 Claude는 정상 전송되지만, ChatGPT와 Gemini는 전송에 실패하는 경우가 있어 원인을 확인하고 있습니다

## 전송이 안 될 때

AI 사이트들이 화면 구조를 바꾸면 입력창이나 전송 버튼을 못 찾을 수 있습니다.

1. `sites.js`에서 해당 사이트의 `input`(입력창) / `send`(전송 버튼) 선택자를 고칩니다
   - 선택자는 위에서부터 순서대로 시도하고, 화면에 보이는 첫 번째 요소를 사용합니다
2. 로그인했는데 🔴로 나오면 `loginCookies`(로그인 쿠키 이름)를 고칩니다
3. `chrome://extensions`에서 이 확장의 새로고침(↻) 버튼을 누릅니다

코드를 수정한 뒤에도 같은 새로고침 버튼을 눌러야 반영됩니다.

## 주의

이 확장은 사용자가 직접 입력하는 것과 같은 방식으로 각 사이트의 화면을 조작합니다.
개인 용도로 사용하고, 각 서비스의 이용 약관을 확인하세요.
